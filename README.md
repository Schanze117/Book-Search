# Book-Search
This is a web space where users can chat about thoughts, react to other user's thoughts, and compile a friend list.

  ## Description
  
  This is a Google Book search application. It is built following a MERN stack and allows users to log in and search for books and add/delete them from their saved list.

  ## Installation
  
  In order to install the required dependencies to run the application, type in the following code 
  ~
  npm i
  ~

  In order to build the application, type in the following code
  ~
  npm run build
  ~
  In order to run the application, type in the following code
  ~
  npm start
  ~
